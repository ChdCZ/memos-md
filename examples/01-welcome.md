# Welcome to memos-md

Every memo is a markdown file under `data/memos/`. This file *is* the memo: the web UI, the API and the
database all read from it.

- [x] the backend mirrors every memo to a file
- [ ] open this file in your editor and change a line
- [ ] restart memos (or wait for the next start) and watch the edit appear in the UI

Copy this file into `data/memos/` to see the format, or delete it once you have your own notes.
